# Счетоводство на НПО Пешачко

Ние сме сдружение в обществена полза (в момента сме в процес на регистрация) и този
GitHub проект ще съдържа нашето счетоводство. За сега аз (Димитър) съм се заел с него.

Аз не съм счетоводител! Всъщност нямам почти никакъв опит в тази сфера, но пък съм готов
да инвестирам време и да се науча. Ако забележите грешки, или имате конструктивни
коментари, **моля** отворете нова
[Issue](https://github.com/peshachko/accounting/issues). Идеята е нашето счетоводство да
бъде отворено за всички. Само по този начин може да се гарантира прозрачност. 

Ще използвам [ledger cli](https://ledger-cli.org/).
