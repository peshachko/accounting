# Счетоводство на НПО Пешачко

Ние сме [сдружение в обществена полза](https://peshachko.bg/) и този GitHub проект ще
съдържа нашето счетоводство. 

За сега аз ([Димитър](https://drdv.net/)) съм се заел с него. Аз не съм счетоводител!
Всъщност нямам почти никакъв опит в тази сфера, но пък съм готов да инвестирам време и
да се науча. Ако забележите грешки, или имате конструктивни коментари/предложения,
**моля** отворете нова [Issue](https://github.com/peshachko/accounting/issues). Идеята е
нашето счетоводство да бъде отворено за всички. Само по този начин може да се гарантира
прозрачност.

## Визуализация 

Скоро ще има и визуализация на счетоводните данни. 

## Счетоводна програма 

Ще използваме [ledger cli](https://ledger-cli.org/).
